Advanced settings
A request that doesn't complete within its timeout counts as failed (AbortError) — that's not proof the connection died, just that it didn't finish in time. Raise these on a slow or high-latency link to stop it misreading "slow" as "lost". The Download/Upload cards stream continuously, back-to-back rounds, for "stream duration" seconds each direction (not one fixed-size request) — the round stall timeout is a safety net per round, not for the whole phase. Changes apply to the next probe/check and are saved for next time.
